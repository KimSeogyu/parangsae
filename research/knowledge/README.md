## 현재 개발 범위와의 거리

저장소 기준은 Binance USD-M / BTCUSDT 우선, 1분~4시간 bar, 수십 분~수일 보유, paper-first다. 미국 주식 월간 팩터 논문과 한국 주식 테마 매매는 이 범위에 바로 이식할 수 없다. 강 수위·해운·날씨 같은 사례는 데이터 시점·경제적 메커니즘을 배우는 확장 연구이며, 현재 BTC 전략 구현의 필수 의존성으로 만들지 않는다.

## 권리·비밀·출처

공개 웹에서 직접 검토한 자료의 짧은 요약과, 별도로 제공된 블로그 발췌자료의 분석 노트를 획득 경로별로 구분해 보관한다. 제공 발췌자료를 현재 공개 웹에서 확인한 원문으로 간주하지 않는다. 공개 열람 가능성과 원문·데이터 재배포 허가는 다르다. 만료·인증 토큰 URL, 사용자 계정 정보, 불필요한 개인/가족 자료, 원본 업로드 전문은 커밋하지 않는다. 원문 설명, 작성자 주장, 독립 검증, 개발 제안은 구분한다. 이후 배치는 이 인덱스와 coverage ledger를 갱신한다.

## 이 문서 묶음의 검토 범위

초기 이관은 지식 문서 78개와 연구 진입 링크였으며, 이후 source-contract 보완은 위 읽기 목록과 각 문서의 coverage ledger에 따로 기록한다. 원출처 검토일과 읽기 제한은 출처별 ledger를 따른다. 문서 이관은 원문 재독해·데이터 재현·전략 검증이 아니며, 현재 저장소에서 확인하지 않은 과거 이슈 번호나 코드 결함 주장을 연결하지 않는다. 공개 원천의 정본 링크와 실제 읽기·매체·접근 제한은 유지한다.
