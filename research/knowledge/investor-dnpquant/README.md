# Dnpquant 투자 아이디어 검토

**제공된 발췌 175개 파일을 모두 읽고 분류했다. 실제 게시글 본문이 식별되는 것은 173개이며, 2개는 명령 출력뿐이다.** 반복 체결 탐지, 거래비용·용량, 평가손익 경로, 전략별 장부, 레짐별 전략 수명은 parangsae의 BTCUSDT 중빈도 연구에 참고할 만하다. 한국 소형주 제도와 개인의 재량 매매를 그대로 이식하거나 자기보고 수익을 검증된 성과로 받아들여서는 안 된다.

## 읽는 순서

1. [연구 종합과 기존 개발 에이전트 검토 항목](research-synthesis.md) — 우선 검토할 P0 운영 항목과 6개 반증 가능한 연구 후보.
2. [175개 파일 검토 인덱스](coverage.md) — 각 ID의 분류·제공본 읽기 상태·노트 위치.
3. [기계 판독 manifest](coverage.json) — 모든 파일의 ID·출처·해시·크기·본문 상태·원문 날짜 표기와 개별 요약, 데이터 필요량, 시간축, 검증·이전 한계.
4. [개별 노트 1](notes/batch1.md) 60개, [개별 노트 2](notes/batch2.md) 60개, [개별 노트 3](notes/batch3.md) 55개 — 본문별 새 요약. 거래일지도 하나씩 읽었으며 같은 테마라는 이유로 생략하지 않았다.

이것은 자료 공급용 문서다. 기존 개발 에이전트가 구현 중인 전략을 대신 만들거나 실행한 것이 아니다. 연구 후보를 시험하려면 현재 저장소의 범위·기존 데이터·위험 정책을 먼저 확인해야 한다.

## 출처와 범위

- 분석일: 2026-10-23 UTC.
- 검토 경로: 제공된 블로그 발췌자료. 원본 파일은 포함하지 않는다.
- 분석 입력: 175개 Markdown 파일, 합계 451,981 bytes. 원본 ID/파일 매핑을 대조했다.
- 원 블로그 주소: [dnpquant](https://blog.naver.com/dnpquant). 노트의 게시글 링크는 제공 메타데이터 또는 파일 ID에서 얻은 주소이며 **온라인 원문이 현재 열리거나 같다는 것을 별도로 검증하지 않았다**.
- 확정된 절대 날짜 표기는 2022-10-01부터 2025-10-08까지 있다. 일부 날짜는 누락됐고 마지막 파일 하나는 상대 날짜뿐이다. 이를 전체 블로그의 최초·최종 글이나 전체 역사적 범위로 해석하지 않는다.
- 이미지·영상·링크된 외부 원문은 보지 않았다. 흐린 썸네일 URL과 사진 설명이 있어도 계좌, 그래프, 대화, 공시의 픽셀 증거를 확인한 것으로 세지 않았다.
- 원시 archive·이미지·긴 인용·개인 생활·가족·상세 잔고·수익 금액을 이 디렉터리에 재게시하지 않았다. 제목은 방법론 중심의 새 설명용 제목이다. 원시 파일명과 터미널에 섞인 개인 경로도 옮기지 않았다.

## 증거를 읽는 규칙

- **저자가 했다는 말 / 제공된 텍스트의 관찰 / 검토자의 새 가설 / 실제 검증 결과**를 구분한다. 이 패키지에는 새로 실행한 백테스트나 감사된 성과가 없다.
- 자기보고 수익, 높은 승률, 여러 해 인증은 독립 감사가 아니다. 전 계좌·현금흐름·포지션·레버리지·미실현손익·실패 전략·비용 없이는 CAGR·Sharpe·MDD·실력/운을 추정하지 않는다.
- “무위험”, “하방이 닫힘”, “본전 손절 가능”, “모든 저점을 잡음”은 검증해야 할 주장이다. 사후 성공으로 사전 위험을 지우지 않는다.
- 시점이 있는 글도 수정 이력이 없으면 엄밀한 사전등록 증거는 아니다. 현재 archive의 문구를 과거 시장 시점에 그대로 사용하지 않는다.
- 과거 규정·세제·법안 설명은 당시 저자의 이해와 의견이다. 현행 법률이나 현재 거래소 규칙으로 확인하지 않았다.
- 가장 중요한 반례는 **강제매도 소진 분석 뒤 반등 실패**와 **정책 위험 해소 확신 뒤 과대 롱 손절**이다. 연구 종합에서 연결해 두었다.

## 검토 재현성

`coverage.json`은 모든 175개 ID를 원래 manifest와 일대일 대조하고 파일 SHA-256, bytes, 포함된 `log_no`, 원문 날짜 표기, 읽기 상태, 개별 분석과 노트 위치를 기록한다. 검토를 세 묶음으로 나눴으나 모두 각 본문을 읽고 새 요약을 작성했다. 제목·키워드만으로 자동 분류한 것이 아니다. 합본의 메타데이터 오귀속, 누락 ID, 반복 ID, 누락 필드, 내부 링크, 개인 경로·계좌 금액의 재유출을 점검했다. 이는 검토 범위의 감사 경로이지 투자 성과의 증명은 아니다.
