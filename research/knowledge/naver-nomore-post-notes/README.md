# No more bets 개발자 읽기 안내

이 자료는 사용자 지정 **금융공학 우회도로 카테고리의 714개 공개 페이지**를 글별로 검토한 기록이다. 원문 저장소나 거래 신호집이 아니다. 기존 `parangsae` 개발자가 개념·단위·데이터 시점·검증 설계의 빈틈을 점검하는 데 사용한다. 현재 코드의 결함이나 구현 완료 여부를 판정한 내용은 아니다.

## 출처와 범위

- [출처별 설명](../naver-sources.md), [714개 전체 색인](../naver-nomore-inventory.md), [기계 판독 manifest](../naver-nomore-manifest.json).
- 공식 표시 712개와 실제 페이지 열거 714개는 불일치한다. 24페이지의 고유 글 ID 714개를 보존했으며 원인은 미확인이다. 전체 블로그 2,116개를 읽었다는 뜻은 아니다.
- `public_text_reviewed`는 접근 가능한 텍스트 검토를 뜻한다. 짧은 공유·미리보기·그림 중심 글은 상세 한계를 함께 읽는다. 외부 기사·논문·책·영상·첨부의 전체 검토로 확장하지 않는다.
- 블로그 주장은 독립 검증된 사실과 다르다. **개발 메모는 독립 추론·확인 질문**이며 실거래 권고가 아니다. 비용·체결·데이터 가용시각·표본외 검증을 별도로 설계한다.
- 공개 열람은 원문·코드·그림 재배포 허락이 아니다. 여기에는 원문 미러 없이 짧은 독자적 메모만 남긴다.

## 복구와 해시 해석

환경 소실 뒤 보존된 목록·manifest와 원작성 기록으로 자료를 복구했다. 공개 원문을 다시 읽어 재작성한 경우는 해당 JSON에서 복구 방식·새 해시·기존 해시와의 비교를 구분한다. 과거 본문 해시는 당시 HTML 문자열 기준이며 원문 내용의 영구 불변성이나 투자 주장의 진위를 증명하지 않는다.
