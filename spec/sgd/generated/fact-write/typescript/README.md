# Generated whole-row TypeScript authority

This portable closed DTO profile derives from the audited Rust source schema, not a TypeScript source binding. For each Fact, call `create<Fact>Row(data)` with every raw field (i64 uses bigint), then call `create<Fact>Owner().write(row)`. Write results preserve the exact source action ID in `effect`; no configurable classifier or action rename table is accepted. Tokens are frozen, authenticated per Fact type and carry payload/provenance from the same complete row. Forged, cloned and cross-type objects are rejected before authority preparation. `read()` exposes only frozen row tokens and copied primitive state. Mutating inputs after token construction has no effect.

Identity encoding: each component is its decimal byte length, colon, lowercase hexadecimal bytes and semicolon. Header components are UTF-8 `sgd-row-v1`, Fact name and `payload` or `provenance`. Ordered fields append field name, kind and value components. Values are signed two's-complement big-endian i64, big-endian u32, one-byte bool (0/1), UTF-8 string or UTF-8 enum variant. Payload finite u32 classes use their minimum member; provenance retains the raw value. No hash or lossy number conversion defines row equality.

All row checks finish before consuming the private primitive preparation. Model origins select whole incoming or retained rows. Mixed payload/provenance origins reject without changing state. This covers one live owner in a trusted realm; application source coverage, partition permission, persistence, aliases to external mutable state and reset prevention require separate contracts.
